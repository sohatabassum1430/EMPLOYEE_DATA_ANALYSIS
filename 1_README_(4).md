# 📊 STAFF — Employee Data Analysis

## 🔍 Project Overview
An end-to-end HR data analysis project built entirely in **Microsoft Excel**, featuring a fully interactive dark-themed dashboard that visualizes key workforce metrics for 8,950+ employees.

---

## 🛠️ Tool Used
- **Microsoft Excel** (Pivot Tables, Charts, Formulas, Slicers)

---

## 📁 Dataset
- **File:** STAFF_EMPLOYEE_DATA_ANALYSIS_.xlsx
- **Records:** 8,950+ employees
- **Source:** HR Employee Dataset

### Columns in Dataset:
| Column | Description |
|--------|-------------|
| Employee_ID | Unique employee identifier |
| First Name / Last Name | Employee name |
| Gender | Male / Female |
| State / City | Employee location |
| Education Level | Bachelor / Master / PhD / High School |
| Birthdate | Date of birth |
| Hiredate | Date of joining |
| Termdate | Date of termination (if applicable) |
| Department | Employee department |
| Job Title | Employee job role |
| Salary | Annual salary |
| Attrition Status | Active / Terminated |
| Performance Rating | Excellent / Good / Satisfactory / Needs Improvement |

## 📋 Sheets Structure
| Sheet Name | Purpose |
|------------|---------|
| EMPLOYEE DASHBOARD | Final interactive dark dashboard |
| STAFF | Raw employee data (15 columns) |
| COUNT IF, SUMIFS & AVG IFS | Count and average formula analysis |
| FILTER FOR >120000, FEMALE | Salary filter formulas |
| MIN, MAX SALARY | Salary range analysis |
| COUNTA FOR DEPT | Department count analysis |
| VLOOKUP, XLOOKUP | Lookup formula practice |
| XLOOKUP WITH MAX | Advanced lookup with max salary |
| FILTER FOR MONTH MARCH | Month-based filtering |
| FILTER FOR WEEKDAYS (MONDAY) | Weekday-based filtering |
| AVG SALARY, OVERALL % AVG | Salary percentage analysis |
| PIE CHART GENDER (DEPT) | Gender by department pivot |
| WORKFORCE SPREAD BY POSITION | Position distribution pivot |
| EMPLOYEE COUNT BY SALARY | Salary bucket analysis |
| MONTHLY TREND LINE | Monthly headcount pivot |
| COUNT OF DEPT (PERFORMANCE) | Performance by department pivot |
| TOP 10 EMPLOYEES | Top earners analysis |
| PERFORMANCE RATING | Performance distribution |
| EMPLOYEE EDUCATION SNAPSHOT | Education level pivot |
